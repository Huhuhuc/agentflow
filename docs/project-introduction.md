# AgentFlow 项目介绍

AgentFlow 是一个面向作品集展示的 AI Agent 工作流编排平台。它的目标不是只做一个静态原型，而是用接近真实生产系统的方式展示“可视化编排、可控执行、可观测运行、可演示交付”的完整产品能力。

## 项目定位

企业在使用 AI Agent 时，常见问题不是模型能不能回答，而是复杂任务如何拆分、每一步如何追踪、失败如何复盘、成本如何统计，以及低置信结果如何交给人工处理。AgentFlow 将这些问题抽象成工作流平台：用户通过可视化节点搭建流程，后端按 DAG 依赖执行节点，并记录每一步状态、日志和模型用量。

## 核心能力

- 可视化工作流构建：基于 React、Vite、React Flow 实现节点式流程编辑。
- DAG 执行引擎：支持图结构校验、拓扑执行、条件分支和节点级状态流转；执行终点由图结构推导（无出边节点，优先 output 类型），分支跳过时仍取实际走通分支的结果。
- 真实 LLM 网关：`llm_mode` 切换真实 OpenAI-compatible 调用与确定性 Mock，支持 system/user 提示词模板、温度与 JSON schema 结构化输出。
- 分级重试策略：429/408/5xx 与网络异常按指数退避重试并遵守服务端 `Retry-After`；鉴权、参数等确定性错误立即失败。重试次数支持全局与节点级配置，实际尝试次数写入节点日志。
- 发布版本管理：工作流发布后生成不可变版本，便于复现和审计。
- 执行日志与监控：记录每次运行、每个节点的输入输出、耗时、状态和错误信息。
- Mock Agent 演示：无需真实付费 API Key，也可以完整跑通 AI Agent 工作流演示。
- 全栈工程交付：包含 FastAPI 后端、PostgreSQL 存储、Redis/Celery 异步执行方案和 Docker Compose 部署。

## 技术方案

前端使用 React/Vite 构建操作界面，用 React Flow 承载节点画布、连线、节点配置和工作流编辑体验。后端使用 FastAPI 提供 REST API 与执行接口，围绕工作流、版本、执行记录、节点日志和租户数据建模。执行层以 DAG 为核心，先校验图结构，再按依赖关系运行节点，并将运行结果持久化。

本地开发支持 inline 执行模式，便于快速调试；Docker Compose 模式下可以接入 PostgreSQL、Redis 和 Celery，展示更接近生产环境的架构形态。

## 演示亮点

1. 打开 Dashboard，展示工作流运行量、成功率、成本和近期运行记录。
2. 进入工作流构建器，查看触发器、Agent、条件、HTTP、通知和输出节点。
3. 修改节点配置，保存并发布一个工作流版本。
4. 运行 Demo 工作流，观察节点按依赖顺序执行。
5. 在运行监控页查看节点日志、Token 用量和成本统计。

## 简历项目表述

**AgentFlow - AI 工作流与反馈处理 Agent | 全栈个人项目**

- 基于 React Flow 与 FastAPI 搭建可视化 AI 工作流平台，支持图结构校验、拓扑执行、条件分支、重试、节点日志和工作流版本管理。
- 设计 PostgreSQL 租户隔离、Redis/Celery 异步执行、JWT 鉴权、SSE 状态推送和 Docker Compose 部署方案。

## 范围说明

当前仓库重点实现工作流编排、DAG 执行、Mock Agent、执行日志、成本统计和可演示的全栈页面。生产级计费、数百个第三方连接器、Kubernetes 部署、多用户实时协作和完整 RAG 管理后台属于后续路线图，不在当前 Demo 的已实现范围内。
