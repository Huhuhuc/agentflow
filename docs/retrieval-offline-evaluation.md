# AgentFlow 离线检索与拒答评测

运行日期：2026-11-14。报告：[`retrieval-bge-abstention-2026-11-14.json`](../backend/evaluation/reports/retrieval-bge-abstention-2026-11-14.json)。

## 目的与范围

比较词法 bigram、BGE 向量和 RRF 混合排序在合成售后政策查询上的表现，并检查系统面对资料中没有答案的问题时，能否拒绝给出无依据结果。该基准是离线实验，不会调用聊天模型，也未接入 AgentFlow 线上业务检索。

资料集含 10 份手工编写的短政策和 36 条查询；30 条有答案、6 条无答案。dev/test 各 18 条，按政策组切分，避免同一政策的改写问题跨集合。数据和标签由项目作者编写，没有独立标注或复核。

## 方法

每条查询计算三种排序的 top-5 Recall 与 MRR。另保存各策略 top-1 分数及是否命中标注政策。分别在 dev 上校准拒答阈值，最大化 balanced outcome rate；并列时依次优先较少误答、较高阈值。阈值冻结后只在 test 上评估。

“正确回答”要求查询有答案、分数达到阈值且 top-1 命中正确政策；“误答”包含无答案却选择回答，以及有答案但 top-1 条款不正确仍选择回答。“正确拒答”是无答案且分数低于阈值。“误拒”是有答案但系统选择拒答。阈值是特定排序器的拒答决策参数，不是模型置信度，也不能跨模型、资料或索引版本直接复用。

## 留出集结果

| 策略 | Recall@5 | 正确回答 | 正确拒答 | 误答 / 无答案数 | 误拒 / 有答案数 | 覆盖率 |
|---|---:|---:|---:|---:|---:|---:|
| 词法 bigram | 15/15 | 13/15 | 3/3 | 0/3 | 2/15 | 13/18 |
| BGE 向量 | 15/15 | 14/15 | 3/3 | 0/3 | 1/15 | 14/18 |
| RRF 混合 | 15/15 | 14/15 | 1/3 | 2/3 | 1/15 | 16/18 |

在这组小型留出集上，向量策略比词法策略多正确回答 1 条，同时少误拒 1 条；混合策略覆盖率最高，但出现 2 条无答案误答。无答案样本只有 3 条，因此 `0/3` 不能解释成稳定的零误答率。所有策略 Recall@5 都是 100%，但这不等于答案正确率，也不代表策略能识别证据缺失。

当前业务接口仍用词法检索；实验结果没有改变线上默认策略。新结果不足以据此宣称 BGE 在真实客户资料上优于现有检索，也不足以启用 RRF 混合检索。

## 复跑

先在当前 Python 环境安装与项目兼容的 `sentence-transformers`，准备本地 BGE 模型目录，然后从 `backend` 执行：

```powershell
python -m evaluation.retrieval_benchmark `
  --model-path D:\LocalAI\embeddings\bge-small-zh-v1.5 `
  --output evaluation\reports\retrieval-bge-abstention-YYYY-MM-DD.json
```

脚本拒绝覆盖已有实验文件。报告包含数据集哈希、模型权重指纹、依赖版本、逐条排序结果、阈值及指标。模型路径只用于本机运行，不要求将权重提交到仓库。

## 后续有效验证

下一步应由非实现者复核查询、标准答案和无答案标签，扩大独立政策组与缺失知识类型，再对同一资料快照进行多次运行。完成标签复核和数据扩展前，这份报告适合作为工程实现演示与问题定位样例，不应作为线上质量承诺或简历中的业务准确率。
